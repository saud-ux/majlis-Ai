# مجلس AI — نسخة أولية قابلة للتشغيل

## إعداد
1. أنشئ مشروع Supabase في الخطة المجانية. في Authentication عطّل التسجيل العام وأنشئ مستخدمك يدويًا. عطّل anonymous sign-ins أيضًا.
2. انسخ `supabase/migrations/001_init.sql` إلى SQL Editor **بعد استبدال UUID الصفري في `is_app_owner` بمعرّف المستخدم الحقيقي**. لا تنفذها بالمعرّف الصفري.
3. انسخ `.env.example` إلى `.env.local` وأدخل Project URL و**publishable/anon** key فقط. لا تستخدم service_role في الواجهة.
4. `npm install && npm run dev`؛ للبناء `npm run build`.
5. يمكن نشر مجلد `dist` على استضافة صفحات ثابتة تدعم SPA fallback. أضف عنوان النشر إلى إعدادات Auth URL في Supabase؛ لا تنشر قبل اختبار تسجيل الدخول والرفض من مستخدم ثانٍ.

## ما يعمل
تسجيل دخول قائم على Supabase؛ عزل بيانات المالك عبر RLS؛ مشاريع ومهام وتعديل وحفظ يدوي عند مغادرة الحقل؛ حالات وأولويات؛ توليد طلبات محلية؛ نسخها وفتح المواقع الرسمية؛ حفظ جولات وردود حقيقية؛ عرض Markdown دون HTML خام؛ رفع وتنزيل ملفات خاصة (10 MB للملف)؛ ذاكرة صريحة؛ نتيجة مع حالة تحقق يحددها المستخدم؛ بحث مهام؛ تصدير بيانات JSON الوصفية؛ تصميم RTL متجاوب.

## قيود مهمة
هذه **نسخة أولية وليست تنفيذًا كاملًا لكل المواصفات**. لا يوجد بعد: مزامنة مسودات تلقائية متينة دون اتصال، استيراد JSON، سجل تراجع، حذف آمن شامل للملفات، مقارنة ردود منظمة، تصدير ZIP/patch، استيراد مستودع GitHub، تحليل ذاكرة دلالي، حزمة تحديث ذاكرة، أو اختبارات E2E للهواتف. لا تدعي الواجهة تنفيذًا تلقائيًا في الأدوات الأخرى. الحفظ عند مغادرة الحقل، وليس عند كل ضغطة؛ تأكد من مؤشر الحفظ. تعارضات تعديل السجل تمنع الكتابة بواسطة رقم النسخة ولكن لا توفر واجهة دمج. قد تتطلب حذف المرفقات يدويًا من Storage قبل/بعد حذف السجلات.

## أمان وتشغيل
لا تشارك ملف `.env.local` ولا تخزن مفاتيح سرية في المشروع. مفتاح anon عام ومقيد بسياسات RLS؛ لا تضع `service_role` في العميل. اختبر رفض الوصول إلى الجداول وStorage لمستخدم آخر قبل النشر. لا تعتمد على فحص الأسرار القائم على regex وحده. الملفات تُرفع كما هي إلى Storage ولا تفحص ضد البرمجيات الخبيثة؛ افتح الملفات بحذر. سياسة نوع الملفات في الواجهة ليست سياسة تخزين خادمية كاملة. تأكد من حدود MIME في إعدادات bucket إذا احتجت حظرًا خادميًا.

## حدود المجانية
حصص Supabase والاستضافة متغيرة حسب التاريخ والخطة وقد تتوقف المشاريع المجانية بسبب الخمول. راجع صفحة التسعير الرسمية قبل النشر؛ لا توجد ضمانات مجانية غير محدودة. اشتراكات ChatGPT/Claude/Gemini لا تتيح API مجانية تلقائيًا؛ التطبيق لا يستدعيها.
